### What I'm usually hired to fix

- **The API that got slower every quarter** — profiling, execution plans, indexing, caching,
  and the honest call about where an ORM should stop and hand-written SQL should start.
- **The monolith nobody can change** — Strangler Fig, not a big bang. New .NET 8 services grow
  beside the old MVC app and take traffic one slice at a time.
- **The security review blocking the deal** — vulnerability remediation, threat modeling,
  OAuth 2.0 / OIDC / SAML / Azure AD done properly.
- **The AI feature that never left the demo** — feature flags, per-tenant quotas, fallbacks and
  monitoring, so it degrades quietly instead of breaking the product.
